# markusluisflores.github.io

Personal resume/portfolio site, live at [markusluisflores.github.io](https://markusluisflores.github.io).

Built with [Eleventy](https://www.11ty.dev/), hand-written CSS/JS, and deployed to GitHub Pages via GitHub Actions. See [ADR-001](docs/adr/ADR-001-static-site-generator.md) for why Eleventy was chosen over Jekyll or a no-build plain HTML/CSS/JS approach.

## Quick Start

```bash
npm install
npm run serve   # local dev server with live reload
npm run build   # compile to _site/
npm run lint    # eslint + stylelint
```
